# 证据报告

使用 [报告模板](../warehouse-anomaly-attribution/assets/report-template.md)。只引用工具提供的结果，不补造数值或因果根因。每个分解标明是否可对账，列出query/plan IDs与release。

保持观察、代数贡献、假设、因果结论的层次。前提被反驳时说明反证；数据不足或工具失败时显示部分证据和停止原因。模板属于输出资产，不是要执行的额外工具指令。
