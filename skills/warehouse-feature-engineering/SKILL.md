# 电商主题数据加工与交付

## 目的
从本地 TheLook 原始表生成 DWD 行为与订单商品明细、DWS 用户商品日汇总、ADS 用户商品画像。
第二阶段扩展用户商品交互日汇总、交互特征与会话观察表，当前共10张输出表。
不训练模型，不创造曝光/点击/支付事实，不将当前订单状态当历史特征。

## 输入与入口
- as_of：UTC 零点的排他截止日期，不晚于源快照观察时间。
- verify_repeat：是否全量重建两次并检查稳定性。
- 独立入口：`scripts/build-feature-mart.ps1 -AsOf 2026-10-11 -VerifyRepeat`。
- Python 执行器：`local_agent.feature_pipeline.build`；入口和参考实际加载并记录资源 hash。
- 此能力不注册到旧查询 SkillRegistry，不开放自然语言任意写表。

## 执行步骤
1. 读取源快照时间与 hash，复制五张 raw 表到独立候选发布目录。
2. dbt 按固定模型清洗、分支预聚合，再生成画像；匿名事件保留。
3. 检查主键、复合粒度、引用、截止窗口及 raw 到 DWS 的计数金额。
4. 对全部用户商品重新计算 7/30 天浏览真值，核对 ADS。
5. 可选重跑并比较全表内容摘要，确保全量替换不产生重复。
6. 输出表契约、技术血缘、质量和运行记录；全部通过才切换 active。

## 停止条件
字段缺失、引用错误、重复原始事件主键、源库复制期间变化、日期越界、dbt 失败、独立对账失败或重跑不稳定时停止。
失败目录保留用于诊断，旧 active 不切换；无生产者水位时明确完整性未验证。

## 运行约束
单次 dbt 构建最长 300 秒，默认串行模型构建。源库只读，目标独立。
无通用重试/分布式锁；并行构建和生产增量属于后续范围。
详细字段、粒度与交付限制见 [表契约](references/table-contracts.md)。
