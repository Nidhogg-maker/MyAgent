# 指标口径与 grain

唯一计算定义在 contracts/commerce.json，本文件只解释决策约束，不重复维护SQL或公式副本。

- orders事实粒度是 order_id；items事实粒度是 order_item_id。订单指标不能直接按品类查询，当前编译器不会猜Join。
- 所有窗口依据UTC下单日期，start包含、end不包含。比较须采用明确等时长基准，不能静默把31天月换成30天。
- 订单量统计全部状态；下单金额不是实收；Complete/Cancelled/Returned仅指当前快照状态。新近 cohort 完成不足可能只是观察时间较短。
- 订单完成/取消/退货占比必须在同窗口、同用户筛选下使用完整分母。禁止按 order_status 过滤或分组这些占比。
- ratio先聚合分子分母再除；不能平均日均比例。不同用户数跨组不可直接求和。零分母返回null，不补0。
- 国家、性别等业务称谓先由维度值解析器链接到实际值。无法匹配的值必须澄清，不能用零结果冒充业务下降。
- 本地Owner是学习项目占位，水位未验证，数据是合成数据；报告保留这些观察条件。
