## 真实运行证据

执行 `scripts/retrieval-phase3-demo.py`：使用真实Dense和Cross-Encoder、模拟决策模型、真实TheLook。没有真实LLM准确率验收，也未调用付费LLM。

自然语言：`2026年9月平均每张订单的金额是多少`。

检索使用10候选成对打分，平均订单金额成为最终指标候选第一名。Agent首次上下文包含真实重排证据，随后调用resolve_semantics读取候选权威定义，按单位选择指标，再run_query并引用实际查询证据结束。

客单价为 `88.22046842854883`；raw.order_items金额 / raw.orders数量独立计算一致。这里是下单金额，不是实收。这个例子证明接入和执行正确，不证明整体模型准确率提高。

同进程重复检索命中重排打分缓存。精确指标和明确歧义检查都跳过重排。

订单量模板复用于两窗口：`[2026-09-01,2026-09-08)` 与 `[2026-09-08,2026-09-15)`，分别得到 `1311`、`1379`，均与raw.orders独立回算一致。第二次模板hit，SQL日期/LIMIT重新绑定，两次实际执行读取各自窗口，没有复用旧数据结果。
