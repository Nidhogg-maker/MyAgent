# 真实模型首次验收

模型：gpt-6.1-sol；使用本机加密配置，经官方 Responses API 实际调用。不是 Mock 验收。

| 问题 | 实际结果 |
|---|---|
| 2026年9月订单数是多少 | COMPLETE，UTC [2026-09-01,2026-10-01)，6,319 单 |
| 2026年9月只看美国的订单数是多少 | 首轮暴露过滤值链接错误，修复后 COMPLETE，country=United States，1,420 单 |
| 2026年9月销售额是多少 | CLARIFY，要求选择下单金额或已完成商品金额 |
| 今天订单数是多少 | CLARIFY，今天尚未结束 |
| 2026年9月下单金额为什么比2026年8月低 | CLARIFY，30天与31天不等长，未擅自更换窗口 |

## 修正与证据

业务词典新增国家名称/缩写到仓库实际值的映射。模型任务在本地通过词典链接后才进行权限、编译和执行校验。美国过滤通过独立 raw.orders/raw.users 查询复核，使用明确 UTC 日期，避免本机时区影响。

修正前的首次记录保留在 openai-live-smoke.json，不视为全部正确；修正后的真实过滤复验在 openai-live-filter-retest.json，包含响应ID、请求ID和token用量。原91项回归通过，新增国家值链接及源表对账测试通过。

这是一组真实冒烟测试，不能推导广泛自然语言准确率或生产可靠性。首次订单总数调用没有保存完整响应文件，数值来自当次实际终端结果。没有执行完整真实模型评测集，也没有完成真实因果归因验收；源快照完整性水位仍未验证。

## 日常使用

```powershell
.\scripts\start-openai.ps1 -Question '2026年9月只看美国的订单数是多少'
```

密钥和模型配置已持久化，无需再次输入。更新配置运行 configure-openai.ps1，使用独立窗口。
